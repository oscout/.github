# Integration mark sources

The illustration generator embeds these existing platform marks. A mark identifies its integration; it does not imply endorsement. Brand rights remain with their owners.

| Asset | Source | Treatment |
| --- | --- | --- |
| Claude | [Claude favicon](https://claude.com/favicon.svg) | Original clay color and geometry. |
| Codex | Codex app icon from the official ChatGPT desktop app, retained as the established Scout icon asset | Embedded PNG preserved. |
| Cursor | [Cursor brand assets](https://cursor.com/brand), Cube 2.5D | Original geometry and tones. |
| pi | [pi favicon](https://pi.dev/favicon.svg) | Original geometry and colors. |
| Hermes | [Nous Research / Hermes Agent](https://github.com/NousResearch/hermes-agent) character | Original image in a rounded avatar tile; [MIT license](./LICENSE-hermes-agent.txt). |
| Herdr | [Herdr](https://herdr.dev) ram, established Scout vector glyph | Original geometry, theme ink, seated in a pane corner. |
| Grok Bot | Established Scout face illustration, redrawn from [Grok Bot](https://x.ai/bot) | Original eye mask and circle; theme ink. |

The Scout glyph is the canonical outlined hexagon with a filled center. Each generated SVG includes a title and description. Nested icons have no external file dependencies.
