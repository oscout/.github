# oscout organization metadata

Use these values when configuring the public GitHub organization.

| Field | Value |
| --- | --- |
| Display name | oscout |
| Description | Open infrastructure for your personal agent cloud. Home of Scout. |
| URL | `https://oscout.net` |
| Avatar | `assets/oscout-avatar.png` |
| Profile README | `profile/README.md` |

The organization profile hero is `profile/assets/org-hero.png`. Keep the org
description broad and use the Scout repository description for the concrete
CLI/runtime promise.

Brand assets match the app and openscout.app: the rounded Scout ring with a
filled inner hex, cream ink on the dark icon, and the approved “Connecting all
your agents” homepage artwork. Upload the avatar in GitHub organization settings.
